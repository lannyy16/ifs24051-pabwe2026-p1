Timpa file-file berikut ke proyek kamu (path sama), lalu jalankan:
  npm install
  cd backend && npm install && npm run dev      (terminal 1, port 3000)
  npm run dev                                   (terminal 2)

File yang berubah:
  index.html                  -> font (Young Serif + Figtree)
  src/index.css               -> stylesheet baru (semua class sudah terdefinisi)
  src/App.jsx                 -> rute lengkap + Layout (header/footer) + AuthProvider
  src/pages/HomePage.jsx      -> field latin/desc, kartu bergambar, lembar spesimen di hero
  src/pages/CatalogPage.jsx   -> field latin/desc, kartu bergambar, baca ?search= dari Finder
  backend/server.js           -> skema field sama dengan data & backend/api/index.js
